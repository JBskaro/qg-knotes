# План развития QG Knotes

Источники идей: Granola, Fellow, Notion, Fathom, Otter (как устроены заметки), Kaneo, Trello, Linear (доска), и пять
открытых проектов, которые прислал владелец 23.10.2026: meeting-transcriber (pasrom), Scriberr, Speech-to-Text-Russian
(stt-ru, GigaAM), realtime-meeting-transcription (Meeting BaaS), Meetily.

Оценки - в часах работы агента. Объем: малый до 4 ч, средний 4-12 ч, крупный больше 12 ч.

## Что уже есть и у них считается сильной стороной

- Предупреждение, что молчит микрофон или звук собеседников (у pasrom - «индикатор тишины дорожки»).
- Восстановление прерванной записи при следующем запуске (Meetily, pasrom).
- Шаблоны протокола данными: семь видов встреч в `виды_встреч.json` (Meetily, Scriberr).
- Повторное распознавание, срок хранения звука, глобальная клавиша записи, действия у значка в трее.
- Блокнот с минутами записи и повестка серией встреч (Granola, Fellow), календарь по ссылке ICS.

## Фаза 1. Быстрые улучшения, около 5-7 ч

1. **Конец встречи - предложить остановить запись.** Программа встречи отпустила микрофон дольше 2 минут -
   плашка «Встреча закончилась? Остановить запись». Если не сделать - запись продолжает писать разговор после
   встречи, две встречи подряд склеиваются в одну (известная беда pasrom). Малый.
2. **Название встречи из окна программы встречи**, когда календаря нет: заголовок окна Teams, Zoom, Телемоста.
   Если не сделать - встреча называется «Teams 22.10 13:54», название и проект ставятся руками. Малый.
3. **Действия по выделению в расшифровке** (Scriberr): выделили фразу - «В заметки», «Задача на доску», «Вопрос
   на доску», «Послушать». Если не сделать - задачу из расшифровки переписывают руками. Малый.
4. **Имена участников из календаря - кнопками в окне участников** (pasrom: быстрые кнопки и образец голоса).
   Если не сделать - «Собеседник 1» переименовывают по памяти, ошибки в именах идут в протокол. Малый.
5. **Вид встречи по названию**: «демо», «показ» - показ доработки, «ЧТЗ», «читка» - согласование ЧТЗ, правила в
   том же файле видов. Если не сделать - в проекте с разными встречами вид выбирают каждый раз. Малый.

## Фаза 2. Проверка и выдача клиенту, около 10-14 ч

6. **Проверка цитаты: пункт протокола - звук основания** (Scriberr, stt-ru: плеер с подсветкой слов). Щелчок по
   пункту проигрывает фразы, из которых он вырос, слова подсвечиваются. Если не сделать - перед отправкой
   клиенту спорный пункт проверяют, листая расшифровку. Средний. Нужно проверить, отдает ли Scribe время слов.
7. **Протокол в DOCX и PDF по бланку компании** (одобрено владельцем 22.10). Если не сделать - клиенту уходит
   текст из буфера, а не документ. Малый-средний, нужен бланк владельца.
8. **Свои виды встреч в настройках** (Meetily: шаблон файлом): разделы, что в них писать, колонки. Если не
   сделать - новый вид добавляется только правкой файла. Средний.
9. **Чат по встрече** (Scriberr): вопрос к одной встрече («что решили по налогам?») с ответом и минутами. Если
   не сделать - за этим идут в Claude через MCP. Малый.

## Фаза 3. Конфиденциальность и качество звука, около 15-25 ч

10. **Русский без облака для клиентов под NDA** (stt-ru: GigaAM-v3 на процессоре, около 230 МБ). Сначала замер на
    10-20 своих фрагментах против Scribe, как `stt-ru evaluate`, решение по цифрам. Если не сделать - запись
    клиента под NDA нельзя расшифровать. Средний-крупный. Риск - внутри дорожки собеседников голоса не
    разделяются.
11. **Эхо с динамиков** (pasrom, stt-ru): фраза собеседника, попавшая в микрофон, не приписывается «Я». По
    умолчанию только предупреждать. Если не сделать - без гарнитуры реплики двоятся. Средний.
12. **Проверка расхождения дорожек на длинной записи** (Meetily #851, pasrom): замер на записи 2 часа. Если не
    сделать - в длинной встрече может перепутаться порядок реплик. Малый (замер), средний (исправление).

## Не делать сейчас

- Живые субтитры во время встречи (Meetily): нагрузка на ноутбук во время звонка, выгода для протокола малая.
- Знакомые голоса от встречи к встрече (pasrom): голос - биометрические данные, нужно письменное согласие.
- Бот во встрече (Meeting BaaS): программа как раз без бота.
- Автоопределение языка: держать русский явно, автоопределение на русской речи выдумывает английский (Meetily #581).
